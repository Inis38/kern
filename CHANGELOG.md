# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.2.0] — 2026-05-30

Изменения относительно коммита `bde2280` (first commit).

### Добавлено

- Раздел **Приложения** (`/apps`): менеджер серверного ПО с расширяемой архитектурой (`ManagedApplication`).
- Первое управляемое приложение — **Nginx**: проверка установки, установка через `apt-get`, настройка виртуального хоста.
- REST API приложений: `GET/POST /api/v1/apps`, `GET/PUT /api/v1/apps/{slug}`, установка и сохранение конфигурации.
- Общие фрагменты Thymeleaf (`fragments/layout`): единая шапка, навигация, футер.
- Интеграционные тесты: рендер страниц, API, smoke-тест полного контекста Spring.
- Запись логов в файл `kern.log` в рабочей директории (рядом с JAR) с ротацией Logback.

### Изменено

- UI: навигация «Мониторинг» / «Приложения» в едином стиле с дашбордом; страницы приложений оформлены как карточки мониторинга.
- Docker Compose: запуск контейнера от `root` для установки пакетов и записи конфигурации Nginx.
- README: разделы про приложения, API, логи и конфигурацию Nginx.

### Исправлено

- Ошибка парсинга Thymeleaf в шапке (`th:class` с именами классов `header__*`).
- Некорректная вёрстка меню из-за вложенных `th:replace` фрагментов шапки.

## [0.1.0] — 2026-05-29

- Первоначальная версия Kern: мониторинг CPU, памяти, дисков, uptime, load average.
- Spring Boot 3, Kotlin, Thymeleaf, OSHI.
- Docker-образ на Ubuntu 24.04, порт 8090.
